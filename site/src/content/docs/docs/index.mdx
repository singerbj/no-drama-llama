No Drama Llama turns a Windows gaming PC into an always-on local AI server that **gets out of
the way when you play**. It runs two kinds of models side by side. When a game starts, it stops
them so the game gets all of your VRAM, and it brings them back once you quit.

It ships as one self-installing Windows app, `no-drama-llama.exe`, that lives in the system tray.

## Two models

<CardGrid>
  <Card title="LLM" icon="document">
    Writes text. [llama.cpp](https://github.com/ggml-org/llama.cpp) runs a
    [Qwen 3.8](https://huggingface.co/unsloth/Qwen3.8-27B-GGUF) model sized for your GPU (or any
    `.gguf` you like), with an OpenAI-compatible API and a chat page at `http://127.0.0.1:8080`.
    See [Chat and API](/docs/guides/api/) and [Models and GPUs](/docs/guides/models/).
  </Card>
  <Card title="Decision model" icon="list-format">
    Answers typed questions about a text: pick an option, score it, yes or no. [Laya](https://ollaya.dev/library/laya),
    served by [Ollaya](https://ollaya.dev), does that in milliseconds at
    `http://127.0.0.1:11435` (`/api/decide`, `/v1/systemone`). Off by default. See
    [Decision model (Laya)](/docs/guides/laya/).
  </Card>
</CardGrid>

Both share the same on/off switch, game pausing, access setting and API key. A typical pattern
is to let the decision model route or triage, and call the LLM only when you need text written.

## How it works

```
  Running ──── a game starts ────►  Paused  ──── game closed for 60 s ────►  Loading ──► Running
  (models on the GPU)              (llama-server and Ollaya                  (models reload)
                                    stopped, VRAM free)
```

1. Every 5 seconds, the app checks for games. It looks at the folders your launchers install
   games into, and at which other apps are using the GPU.
2. When it finds a game, it stops `llama-server` (and Ollaya, when the decision model is on) and
   shows a small popup that doesn't take focus.
3. When the game has been closed for `ResumeAfterSec` (60 seconds by default), it starts the
   models again.

The rest of the time, the LLM serves `http://127.0.0.1:8080` and the decision model serves
`http://127.0.0.1:11435`.

## Features

<CardGrid>
  <Card title="Fits any GPU" icon="laptop">
    NVIDIA, AMD or Intel. The installer picks CUDA or Vulkan, and llama.cpp sizes the context
    and GPU layers to your free VRAM. See [Models and GPUs](/docs/guides/models/).
  </Card>
  <Card title="Game detection" icon="magnifier">
    Reads the records of Steam, Epic, GOG, EA, Ubisoft, Battle.net, Riot, Xbox and more, and
    watches per-process GPU use. See [Game detection](/docs/guides/game-detection/).
  </Card>
  <Card title="OpenAI-compatible API" icon="seti:json">
    Use any OpenAI client, editor plugin or agent. See [Chat and API](/docs/guides/api/).
  </Card>
  <Card title="Tray app" icon="setting">
    Status at a glance, every setting in the right-click menu and the settings window, and
    Ctrl+Alt+L to turn both models on or off. See [Tray menu](/docs/reference/tray-menu/).
  </Card>
  <Card title="Always on, low power" icon="moon">
    No sleep, screen off after 10 minutes, power saving and Wake-on-LAN. See
    [Always-on PC](/docs/guides/always-on/).
  </Card>
  <Card title="Signed auto-update" icon="approve-check">
    Installs only releases signed with the project key. See [Updates](/docs/guides/updates/).
  </Card>
</CardGrid>
