Status dot for the five tray tones plus "game" — the most important signal in the brand.
```jsx
<StatusDot tone="running" size="lg" />
<StatusDot tone="loading" />   {/* pulses */}
<StatusDot tone="paused" size="sm" />
```
Solid dots only — no halos or rings (hard rule).
Tones: running (mint), loading (marigold), paused (sky), off (pebble), error (tomato), game (grape).
